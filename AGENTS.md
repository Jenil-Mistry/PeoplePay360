# PeoplePay360 Project Guidelines

## Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **UI Library**: React
- **Styling**: Tailwind CSS

## Frontend & Skill Directives
Refer to [.agents/rules/frontend-skills.md](.agents/rules/frontend-skills.md) for full details:
- **Primary Component System**: `shadcn/ui` is the primary foundation for all UI components.
- **Design & Layout**: Use `Frontend Design` and `Taste v2` for distinct, anti-generic visual identity.
- **Visual Polish**: Use `Impeccable` for typography, spacing, color, and UX review.
- **Animations**: Use `Motion` (Framer Motion) for purposeful micro-interactions and smooth feedback.
- **Optional**: `Kokonut UI` is strictly optional and secondary; use only when it genuinely elevates specific interactive components.
- **Excluded**: Do NOT use `Odoo / OWL` or `Aceternity UI`.

## Git & Version Control Directives
- **No Automatic Commits or Pushes**: Never run `git commit` or `git push` unless the user explicitly asks to do so.
